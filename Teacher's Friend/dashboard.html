வழிகாட்டுதல்கள்

வகுப்பறை பகுதியை சிறப்பாக மேலாண்மை செய்ய பின்வரும் வழிகாட்டுதல்களை கடைபிடிக்கவும்:


1. Office Room பகுதியில் உள்ள Data input button யை கிளிக் செய்து அதில் உள்ள School data, Teachers data, students data, census data ஆகிய நான்கையும் முழுவதுமாக பூர்த்தி செய்து Save செய்து கொள்ளவும்.


2. working day's data ஒவ்வொரு மாத முடிவிலும் update செய்யவும்.


3. Marks data ஒவ்வொரு பருவத்தின் முடிவிலோ அல்லது அவ்வப்போதோ Update செய்து கொள்ளலாம்.


4. ஒவ்வொரு மாதமும் working day's data Update செய்த பிறகு Forms button கிளிக் செய்து மாதாந்திர அறிக்கை download செய்து கொள்ளலாம். Admission form, Study certificate, Leave forms, Loan forms, என அனைத்து வகை படிவங்களையும் இப்பகுதியில் download செய்து கொள்ளலாம்.


5. Registers பகுதியில் Marks data update செய்த பிறகு ஒவ்வொரு பருவத்திற்கும் CCE பதிவேடுகள் download செய்து கொள்ளலாம் தேவைப்படும் பொழுது இதர பதிவேடுகளையும் download செய்து கொள்ளலாம்.


6. Daily Homework பகுதியில் நாள் தேர்வு செய்து வகுப்பை தேர்வு செய்து Send கிளிக் செய்தால் மாணவர்களுக்கு அன்றைய நாளுக்கான வீட்டுப்பாடம் தானாக சென்று விடும். மாணவர்கள் அவர்களது login ல் நுழைந்த உடன் அன்றைய வீட்டுப்பாடம் திரையில் தெரியும். ஆசிரியர் பள்ளி நேரத்தில் வீட்டுப்பாடம் வழங்க முடியாமல் போனால், பேருந்தில் செல்லும்போது அல்லது வீட்டிற்கு சென்ற பிறகு கூட மாணவர்களுக்கு வீட்டுப் பாடத்தை அனுப்பி விட முடியும்.


7. Daily Message பகுதியில் அந்த நாளுக்கான சிறப்புகள் பற்றிய குறிப்புகள் ஒவ்வொரு நாளுக்கும் இருக்கும். ஆசிரியர் காலை வழிபாட்டுக் கூட்டத்திலோ அல்லது வகுப்பறையின் போது கூடுதல் தகவல்களாக சொல்வதற்கு பயன்படுத்திக் கொள்ளலாம்.


8. Book Back Q&A பகுதியில் ஒவ்வொரு வகுப்பிற்கும் ஒவ்வொரு பாடத்திற்கும் புத்தக கேள்விகளுக்கான விடைகள் இருக்கும். ஆசிரியர் Screen Cast செய்வதன் மூலம் Smart board அல்லது TV யில் பார்த்து மாணவர்கள் விடைகளை குறிப்பேட்டில் எழுதிக் கொள்ள பயன்படுத்திக் கொள்ளலாம்.


9. Lesson Plan பகுதியில் ஒவ்வொரு பாடத்திற்கான பாட குறிப்பினை பார்த்து பயன்படுத்திக் கொள்ளலாம்.


10. Exam பகுதியில் ஒவ்வொரு வாரத்திற்கான வாராந்திர தேர்வுகள் மற்றும் மாதாந்திர தேர்வு ஆகியவை கொடுக்கப்பட்டுள்ளது. Games பகுதியில் தமிழ், ஆங்கிலம், கணிதம் பகுதிகளில் அறிவுத்திறன் மற்றும் மொழித்திறனை வளர்க்கும் வகையிலான விளையாட்டுகள் நிறைந்த பகுதி. இதை Screen Cast மூலம் அனைத்து மாணவர்களும் பங்கேற்று ஆர்வமுடன் விளையாட செய்வதன் மூலம் கற்றலில் ஆர்வத்தை ஏற்படுத்தலாம்.


11. மேலே வலது புறம் உள்ள Office Room icon ஐ கிளிக் செய்து பள்ளி அலுவலகப் பகுதிக்கும், Staff Room icon ஐ கிளிக் செய்து ஆசிரியர்கள் Social Media பகுதிக்கும் செல்லலாம்.
